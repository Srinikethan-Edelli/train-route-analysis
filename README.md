# 🚆 Train Route Analysis & Journey Time Prediction

## 📌 Project Overview
This project analyzes train route data and predicts journey duration using Machine Learning.

## 🔧 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib & Seaborn
- Scikit-learn

## 📊 Steps Performed
- Data Cleaning & Preprocessing
- Handling missing values
- Time conversion (datetime)
- Feature Engineering
- Handling overnight journeys
- Data Visualization
- Model Building using Linear Regression

## 🤖 Model
Used Linear Regression to predict journey duration based on distance.

## 📈 Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)

## 🎯 Outcome
Successfully built a predictive model and handled real-world data challenges.
